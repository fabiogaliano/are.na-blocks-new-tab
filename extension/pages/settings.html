      About

      About this project

      are.na blocks new tab swaps the default new tab for a curated selection of Are.na content. Each new tab pulls blocks from the sources you enable.

      This is a personal fork of the original extension made by Leon (lok.computer, @lok on Are.na). The original lives on GitHub and in the Chrome Web Store.

      How manual sources work

      Use channel slugs to pull blocks from public channels, and add individual block IDs when you want precise picks.

      Channel example: https://www.are.na/lok/ephemeral-visions → ephemeral-visions

      Block example: https://www.are.na/block/40240825 → 40240825

      New to Are.na?

      Are.na is a creative research platform for collecting ideas, references, and projects. Visit are.na to browse or create an account.
